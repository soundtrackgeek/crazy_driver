# Crazy Driver

A 90s-style arcade racer (think Screamer / Sega Rally on DOS) for the browser, built with three.js. Low-poly "blocky but nice" 3D, procedural scenery, Blender-generated assets and a built-in track editor.

See [docs/PLAN.md](docs/PLAN.md) for the stack, approach, graphics/asset pipeline, audio and milestones.

## Status
- **M0 (scaffold)** done: Vite + TypeScript + three.js, fixed-timestep loop, low-resolution retro renderer, unified keyboard/gamepad/touch input.
- **M1 (drivable car)** done: arcade rigid-body vehicle (raycast suspension, grip-budget tyres, auto gearbox, handbrake drifts, jumps with self-levelling, flip recovery) on a test ground with a ramp, bumps, gravel hills and grass.
- **M2 (spline tracks)** done: tracks defined as JSON control points, built into a banked road with kerbs, edge lines, walls, start gate and checkpoint gates; laps, checkpoints, lap times, wrong-way warning and a minimap.
- **M3 (Blender pipeline)** done: all 3D assets are generated by Python scripts run in headless Blender and exported as `.glb`; a rally car with liveries and 11 roadside props placed automatically along the track.
- **M4 (scenery)** done: procedural terrain that blends into the road (cuttings and embankments), a sky dome with low-poly mountains, sun and clouds, and five themes (grassland, forest, desert, alpine, coastal) that set the sky, fog, light, ground colours and vegetation.
- **M5 (audio)** done: all sound is synthesised with Web Audio (no sample files): an engine that follows the revs and throttle, tyre squeal, gravel crunch, wind, impacts and landings, race jingles, a speech announcer, a 3-2-1-GO countdown, an original two-song tracker soundtrack, and your own music files.
- **M6 (track editor)** done: build tracks in a 3D editor with live preview, undo/redo, validation warnings, a saved-track library, JSON download/upload and one-key test drives.
- **M7 (race game)** done: menus, three modes (Arcade, Time Trial, Quick Race), AI opponents with racing lines and catch-up, car-to-car collisions, race positions, results, pause, ghost cars and per-track records.
- **M8 (content)** done: three cars with distinct handling and eight colour schemes, and four themed tracks plus the test circuit.

## Getting started
Requires Node.js 20+.

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # type-check + production build into dist/
npm test         # physics tests (Vitest)
```

## Game modes
- **Arcade:** race 5 opponents against the clock, Sega Rally style. Every checkpoint and lap gives **EXTENDED PLAY**; if the timer reaches zero it's game over.
- **Time Trial:** drive alone against a ghost of your best lap. Best lap and best race times are saved per track layout.
- **Quick Race:** choose the laps (1–9) and opponents (1–7).

Pick the track (built-in or saved from the editor), your car and its colours in the setup menu.

### Cars
| Car | Drive | Character |
|---|---|---|
| Rally Hatch | 4WD | All-rounder with extra grip on gravel and grass |
| Muscle Coupe | Rear | Heavy, big torque, slides easily; best top speed, weak off-road |
| Wedge GT | Mid-engine, rear | Light, lots of grip and downforce on tarmac; nervous on dirt |

### Tracks
| Track | Theme | Notes |
|---|---|---|
| Canyon Dash | Desert | Fast, banked sweepers and a gravel back section |
| Alpine Pass | Alpine | Short and twisty, climbs about 30 m, gravel switchback |
| Coastal Run | Coastal | Fast seaside sweepers and a chicane |
| Forest Rally | Forest | Narrow, almost all gravel |
| Test Circuit | Grassland | Mixed layout with a hairpin | Menus work with arrows + Enter/Esc, mouse/touch, or a gamepad (d-pad/stick, A, B). Press **Esc** or **P** in a race to pause.

`?track=<file>` skips the menus and starts a quick race on that track.

Open the track editor at `http://localhost:5173/editor.html`.

Load a different track with `?track=<name>`, which reads `public/assets/tracks/<name>.track.json` (default: `test-circuit`). Override its theme with `?theme=grassland|forest|desert|alpine|coastal`.

## Sound & music
Press **M** (or the ♪ button) to open the sound panel. It has master, music and effects volumes, the music mode, the announcer toggle and your music library.

- **Built-in soundtrack:** original songs written as tracker patterns in `src/audio/songs.ts` and played by a small synth sequencer (`src/audio/Tracker.ts`). Each channel is a list of 16th-note steps: a note such as `A2`, `-` to hold, `.` for a rest, and `x`/`X` for drum hits.
- **Your own music:** use *Add music files…* to pick MP3/OGG/any audio files your browser can play. They are stored in the browser (IndexedDB), so they stay between sessions. Set the music mode to *My music only* or *Built-in + my music*.
- Settings are saved in `localStorage`.

## 3D assets (Blender)
Every model is built by code in `blender/`. Nothing is modelled by hand, so assets are reproducible and easy to change. The generated `.glb` files are committed, so you only need Blender if you change the scripts.

```bash
npm run assets                          # rebuild public/assets/models/*.glb
npm run assets -- --preview previews    # also render PNG previews
npm run assets -- --only car_rally      # rebuild one asset file
```

Blender 4.2+ is required (tested with 5.1). The script looks in the standard install locations; set `BLENDER=/path/to/blender` otherwise.

- `blender/lib/mesh.py`: low-poly mesh builder (lofts, boxes, cylinders, blobs) that works in game coordinates (+Y up, +Z forward) with flat per-face vertex colours.
- `blender/lib/palette.py`: shared colours. `PAINT` (magenta) and `PAINT2` (cyan) are livery keys that the game replaces with a car's colours.
- `blender/cars/`: cars (body plus one wheel mesh, origin at the centre of mass).
- `blender/props/`: roadside props (origin at the base, +Z faces the road).

## Track editor
`editor.html` edits the same `*.track.json` format the game uses, rendered with the real road, terrain and props.

| Action | How |
|---|---|
| Select / move a point | Click / drag a yellow handle (green = start line) |
| Change a point's height | Shift + drag |
| Add a point | Double-click; it is inserted into the nearest segment |
| Delete a point | Delete / Backspace (at least 4 points) |
| Camera | Right-drag: pan, middle-drag: rotate, wheel: zoom, *Top view* button |
| Undo / redo | Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) |
| Test drive | T or the *Test drive* button: drives from the selected point; Esc returns to the editor |

The side panel edits the name, theme, laps, prop and terrain seeds, density and hill height, plus each point's position, width, banking and surface. *Issues* lists overlapping sections (crossings are not supported yet), very tight corners and very steep slopes, with markers in the 3D view; click an issue to jump to it.

The working copy is autosaved in the browser. *Save* adds the track to the browser library, *Download*/*Upload* exchange `.track.json` files, and the game can load a saved track with `?track=@saved:<name>`.

## Track format
Tracks are JSON files (`*.track.json`). The road is a smooth closed curve through the control points:

```jsonc
{
  "version": 1,
  "name": "Test Circuit",
  "theme": "grassland",
  "closed": true,
  "laps": 3,
  "controlPoints": [
    { "p": [0, 0, 0], "width": 14 },                 // x, height, z in metres
    { "p": [-30, 3, 250], "width": 13, "bank": 6 },  // bank in degrees, + = right side lower
    { "p": [-280, 6, 190], "surface": "gravel" }     // asphalt (default) | gravel | grass
  ],
  "checkpoints": [0.25, 0.5, 0.75],                  // fractions of the lap
  "scenery": { "seed": 1234, "density": 0.7 },      // prop placement seed and density
  "terrain": { "seed": 7, "amplitude": 25 }          // landscape seed; amplitude defaults to the theme's
}
```

## Tuning the handling
In dev builds (`npm run dev`) press **F1** for a live tuning panel covering suspension, engine, tyres and handling. Use **Copy JSON** to copy the current values, then paste them into `src/physics/VehicleParams.ts` to make them the defaults. The car is also exposed as `window.vehicle` in the browser console.
